# EDA нефтеперерабатывающего процесса

Для передачи проекта другому агенту начинать с `MASTER_AGENT_HANDOFF.md`. В нём собраны актуальная постановка, данные, уточнения организаторов, результаты моделей, сервер A100, ограничения и следующий план без необходимости читать историю чата.

Ноутбуки читают исходные файлы **только** из `../data` и не изменяют их.

Порядок запуска:

1. `00_inventory.ipynb` — инвентаризация, покрытие, пропущенные источники, честный data dictionary.
2. `01_telemetry_quality.ipynb` — качество данных, распределения, gaps, frozen/constant/noisy signals, jumps.
3. `02_time_alignment_and_lags.ipynb` — синхронизация АВТ и 24-2000 по времени, timeline и исследовательские lagged associations.
4. `03_forensic_findings.ipynb` — проверка расхождений в тегах, единицах, ЛИМС/ПАК и формулах ВАК. Он читает Excel-источники из `../docs`.
5. `04_f30_analysis.ipynb` — профиль F30, контроль через W70, связи с АВТ/24-2000, лаги до ЛИМС и устойчивость по годам.
6. `05_w70_f30_ratio.ipynb` — вариабельность W70/F30, изменения за 10 минут, временной дрейф и связи с другими параметрами.
7. `06_lims_gpu_experiments.ipynb` — первый пакет GPU-моделей на реальном ЛИМС, независимый выбор по validation и оценка 2026.
8. `07_lims_walkforward.ipynb` — ретроспективная устойчивость в 2024/2025, прошлые анализы с задержкой, интервалы и ошибки предупреждений по сере.
9. `08_overnight_a100.ipynb` — прогресс и итоги длительного GPU-поиска; инструкции по серверу и чтению результатов в `OVERNIGHT_A100_HANDOFF.md`.
10. `09_overnight_review.ipynb` — разбор результатов: одинаковые baseline, разброс seeds, пропуски серы, интервалы, зависимость от Q21. Полные выводы: `OVERNIGHT_REVIEW.md`.
11. `10_q21_analysis.ipynb` — Q21: код 307, сравнение с ЛИМС/ПАК, 30 контролируемых GPU-обучений. Полные выводы: `Q21_FINDINGS.md`.
12. `11_f31_t33_t55_relationship.ipynb` — связь расхода F31 с температурами T33/T55: режимы, приращения и лаги.
13. `12_q21_target_asymmetric.ipynb` — Q21 как таргет: прогноз 1/3/6 ч и асимметричный штраф за превышение 10 ppm. Полные выводы: `Q21_TARGET_RESULTS.md`.
14. `13_cetane_density_shap.ipynb` — цетановое число: добавочная ценность `W70/F30`, residual-модель, SHAP-устойчивость и сценарная граница 51. Полные выводы: `CETANE_DENSITY_SHAP_FINDINGS.md`.

Архивные подробности обучения и ранних запусков: `AGENT_TRAINING_HANDOFF.md`.

Дополнение `ORGANIZER_QA_UPDATE.md` фиксирует выводы из новых схем АВТ и Q&A от 11.09.2026, включая физическую интерпретацию `W70/F30` как proxy плотности.

Анализ W70/F30 без Jupyter:

```bash
uv run --project project python eda/run_w70_f30_ratio.py
```

Команду можно выполнять из корня проекта `Нефтекод`.

Таблицы-результаты сохраняются в `artifacts/`, графики остаются интерактивными в ноутбуках.

Рекомендуемые пакеты: `pandas`, `numpy`, `plotly`, `scipy`, `openpyxl`, `jupyter`.

Важно: без файлов ЛИМС, ПАК и справочника тегов в `data/` нельзя обоснованно определить target, control variables, физический смысл тегов или сравнить ЛИМС–ПАК.
