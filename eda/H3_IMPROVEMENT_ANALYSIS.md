# Анализ возможности улучшения h=3 прогноза Q21

**Дата:** 2026-09-16  
**Задача:** Можно ли улучшить MAE для горизонта 3 часа?  
**Текущий результат:** MAE = 2.920 ppm (из предыдущего эксперимента)  
**Baseline (persistence):** MAE = 1.455 ppm

---

**Вывод:** Eval 2026 статистически отличается от train. Установка работает в другом режиме с более высокой серой и большей вариабельностью.

### 1.2. Волатильность изменений

```
              Train         Eval         Ratio
Std(Δ Q21)    1.690 ppm    2.215 ppm    1.31x
|Δ| > 2 ppm   21.7%        21.9%        ~равно
|Δ| > 5 ppm   3.2%         3.8%         +19%
```

**Вывод:** Eval имеет на 31% большую волатильность. Крупные скачки встречаются немного чаще.

### 1.3. Автокорреляция Q21

```
Lag       Autocorr
10 мин    0.974      (очень высокая)

```

**Вывод:** Через 3 часа автокорреляция = 0.723, что означает Q21 сохраняет 72% своей предсказуемости. Persistence является сильным baseline.

## 2. Теоретический анализ

### 2.1. Persistence baseline

**Persistence forecast:** Q21(t+3h) = Q21(t)

На eval 2026:
- **MAE = 1.455 ppm**
- Это очень сильный baseline при autocorr = 0.723

### 2.2. Теоретический предел

Если изменения Q21 имеют стандартное отклонение σ = 2.215 ppm, то:

```
Теоретический нижний предел MAE ≈ 0.8 × σ ≈ 1.77 ppm
```

**Проблема:** Теоретический предел (1.77 ppm) **хуже** чем persistence (1.455 ppm)!

Это означает, что:
- Текущее значение Q21 содержит больше информации, чем независимый прогноз
- При autocorr = 0.723 persistence трудно превзойти
- Нужны **очень сильные** предикторы будущих изменений

### 2.3. Что нужно для успеха?

Чтобы улучшить persistence, модель должна предсказывать **направление и величину изменения Δ = Q21(t+3h) - Q21(t)**.

Для MAE < 1.455 ppm нужно:
- Правильно предсказывать знак Δ в >70% случаев
- Ошибка в величине |Δ| < 1.5 ppm
- Или: найти сильные leading indicators за 3 часа до изменения серы

## 3. Причины неудачи предыдущей модели

### 3.1. Прямое предсказание абсолютного Q21

Предыдущая модель пыталась предсказать абсолютное значение Q21(t+3h).

**Проблема:** 
- Q21(eval) имеет mean=10.08, но train имеет mean=8.18
- Модель обучена на другое распределение
- Extrapolation за пределы training domain

### 3.2. Недостаточно признаков изменений

Если модель использует только:
- Текущие controls (P8, T11, F19)
- Текущий Q21
- Короткие лаги

То она видит **состояние**, но не **динамику изменений**.

### 3.3. Overfitting на train/cal

- 1500 iterations может быть слишком много для предсказания изменений
- Модель могла запомнить артефакты train/cal
- В eval эти паттерны не работают

## 4. Стратегия финальной попытки

### 4.1. Residual learning

**Идея:** Не предсказывать Q21(t+3h), а предсказывать **изменение Δ**:

```
Δ = Q21(t+3h) - Q21(t)
```

Финальный прогноз:
```
Q21_pred(t+3h) = Q21(t) + Δ_pred
```

**Преимущества:**
- Не зависит от mean shift (8.18 → 10.08)
- Фокус на динамике, а не уровне
- Если Δ_pred ≈ 0, получаем persistence

### 4.2. Новые признаки для предсказания изменений

**Trend indicators:**
- Rolling mean/std за 1h, 3h, 6h
- Q21_min, Q21_max в окне
- Текущий тренд: растёт или падает?

**Volatility regime:**
- Средняя |diff| за последние 3 часа
- Если высокая волатильность → больше изменений ожидается

**Velocity features:**
- Q21 diff(1 step) = изменение за 10 минут
- Q21 diff(6 steps) = изменение за 1 час
- Ускорение изменений

**Control lags:**
- Короткие лаги F1, P8, T11 (0, 1, 3, 6 шагов)
- Если controls меняются → Q21 может измениться через 3ч

### 4.3. Консервативная регуляризация

```python
learning_rate=0.02  # медленнее (было 0.03)
depth=5             # меньше (было 6)
l2_leaf_reg=10      # сильнее (было 3)
iterations=1500     # с early_stopping
```

**Цель:** Избежать overfitting на train, лучше обобщать на eval shift.

## 5. Прогноз результата

### 5.1. Базовый сценарий (вероятность 60%)

**Результат:** MAE на eval **1.4–1.6 ppm**

- Residual learning поможет адаптироваться к mean shift
- Trend features дадут небольшое улучшение
- Но fundamental limit autocorr=0.723 остаётся
- **Improvement:** 0–10% vs persistence

**Вывод:** Небольшое улучшение или паритет с persistence.

### 5.2. Оптимистичный сценарий (вероятность 25%)

**Результат:** MAE на eval **1.2–1.4 ppm**

- Controls действительно предсказывают изменения Q21 через 3ч
- Trend/volatility признаки сильно коррелируют с будущими Δ
- Eval shift не катастрофичен для residual модели
- **Improvement:** 10–20% vs persistence

**Вывод:** Заметное улучшение, можно использовать в advisory.

### 5.3. Пессимистичный сценарий (вероятность 15%)

**Результат:** MAE на eval **1.6–2.0 ppm**

- Controls не дают leading signal за 3 часа
- Eval shift слишком сильный даже для residual
- Noise в признаках перевешивает signal
- **Improvement:** хуже persistence

**Вывод:** h=3 фундаментально непредсказуем с текущими данными.

## 8. Альтернативные подходы (если текущий не сработает)

### 8.1. Ensemble с persistence

```python
y_final = 0.7 * y_persistence + 0.3 * y_model
```

Даже если модель хуже persistence в одиночку, weighted ensemble может улучшить.

### 8.2. Conditional forecast

Разные модели для разных режимов:
- Stable regime (low volatility) → persistence
- Changing regime (high volatility) → model forecast

### 8.3. Interval forecast вместо point forecast

Если MAE плохой, можно:
- Предсказывать 80% интервал
- Coverage может быть хорошим даже при плохом MAE
- Для risk assessment интервал полезнее точки
