# Summary по тегам AVT и 242000

## 1. Главное правило

Нельзя определять физический смысл тега только по первой букве.

По ТЗ смысл тега нужно брать из справочника КИП, а единицы измерения — хранить и описывать явно.

При этом по текущим материалам:

- для `avt_tags` буквенная логика в основном работает;
- для `242000_tags` первая буква не всегда соответствует физической величине.

---

## 2. Что удалось уверенно установить для `avt_tags`

По значениям, справочнику и PDF-схеме АВТ:

- `T` → температура;
- `P` → давление / вакуум / перепад давления;
- `F` → расход;
- `L` → уровень;
- `D` → плотность;
- `W` → массовый расход.

Это согласуется с расположением приборов `TI/TC`, `PI/PIC/PDC`, `FI/FC`, `LI/LC` на PDF-схеме АВТ.

Примеры хорошо подтверждённых тегов:

- `AVT:T6` → температура низа К-1;
- `F7/F8/F9` → расходы потоков обессоленной нефти;
- `P67` → давление верха К-2;
- `T37` → температура ВЦО К-10;
- `F46` → расход НЦО К-10;
- `W70` → массовый расход фракции 290–350 °C.

---

## 3. Важный вывод по `AVT:T6`

Текущий вывод:

```text
AVT:T6
→ температура низа К-1
→ значение около 234 °C
→ соответствует температурному прибору в нижней части К-1
```

Уверенность: **очень высокая, порядка 99%+**.

---

## 4. Важный вывод по `W70`

Для `avt_tags` гипотеза `W = mass/weight flow` хорошо подтверждается.

Пример:

```text
F30 ≈ 98.97
W70 ≈ 77.38
```

Отношение:

```text
W70 / F30 ≈ 0.782
```

Если `F30` — объёмный расход, а `W70` — массовый расход, это даёт плотность около:

```text
782 кг/м³
```

Это выглядит физически правдоподобно для лёгкой нефтяной/дизельной фракции.

---

## 5. Для `242000_tags` буквы нельзя трактовать напрямую

По справочнику встречаются ситуации, где короткое имя не совпадает с ожидаемым физическим типом.

Например, по справочнику:

```text
242000:T6
→ поточный анализатор серы
```

Хотя буква `T` обычно ассоциировалась бы с температурой.

Поэтому для установки 24-2000 нужен явный mapping:

```text
короткий тег
→ описание КИП
→ физическая величина
→ единицы
→ оборудование
```

а не автоматическая расшифровка по первой букве.

---

## 6. Самая спорная точка — `242000:T6`

По справочнику:

```text
242000:T6
→ поточный анализатор серы
```

Но по самим данным есть сомнение.

Пример:

```text
T5 ≈ 365 → 361 → 363
T6 ≈ 360 → 355 → 358
```

На небольшом фрагменте:

```text
corr(T5, T6) ≈ 0.95
```

Разница примерно:

```text
T5 - T6 ≈ 4.4–6.5
```

По динамике это выглядит как две температуры одного технологического тракта сильнее, чем как:

```text
температура + анализатор серы
```

Поэтому текущий статус:

```text
AVT:T6
→ confirmed

242000:T6
→ значение из справочника известно,
  но физический смысл нужно дополнительно проверить по данным
```

То есть `242000:T6` пока нельзя считать на 100% подтверждённым анализатором серы.

---

## 7. Что нужно сделать для окончательной проверки `242000:T6`

Нужно взять более длинный временной ряд и проверить:

1. корреляцию `T6` с `T5`;
2. временные лаги между `T5` и `T6`;
3. устойчивость разности `T5 - T6`;
4. корреляцию `T6` с ПАК-серой;
5. корреляцию `T6` с ЛИМС-серой;
6. связь `T6` с другими серными сигналами;
7. диапазон `T6` за месяцы/годы;
8. поведение `T6` при смене технологического режима.

Ключевая проверка:

```text
242000:T6 ↔ ПАК sulfur
```

против:

```text
242000:T6 ↔ технологические температуры
```

Если `T6` намного сильнее связан с температурными тегами, чем с серой, это может означать ошибочное или сдвинутое сопоставление в справочнике.

---

## 8. PDF-схема не подходит для проверки `242000_tags`

Текущий PDF относится к АВТ.

`242000_tags` — это уже установка гидроочистки/стабилизации 24-2000.

Поэтому:

```text
PDF АВТ
→ можно использовать для проверки avt_tags

PDF АВТ
→ нельзя использовать для физического размещения 242000_tags
```

Для проверки `242000_tags` нужна технологическая схема установки 24-2000.

---

## 9. Как лучше хранить mapping в проекте

Лучше не оставлять модели сырые имена типа `T6`, `F30`, `P67`.

Рекомендуемый формат:

```python
{
    "source": "avt",
    "raw_tag": "T6",
    "semantic_name": "k1_bottom_temperature",
    "equipment": "K-1",
    "physical_type": "temperature",
    "unit": "degC",
    "status": "confirmed"
}
```

Для спорных тегов:

```python
{
    "source": "242000",
    "raw_tag": "T6",
    "semantic_name": "unknown_or_sulfur_analyzer",
    "physical_type": "needs_validation",
    "status": "dictionary_only_needs_validation"
}
```

## 10. Итоговый вывод

Сейчас разумно считать:

```text
AVT:
буквенная структура в основном соответствует физическим величинам
и подтверждается схемой.

242000:
короткие имена нельзя интерпретировать по буквам;
нужен справочник + статистическая проверка по временному ряду.
```

Рабочий принцип для дальнейшего обучения и разработки:

```text
справочник
→ первичный источник смысла

PDF / технологическая схема
→ проверка физической правдоподобности и положения тега

реальные временные ряды
→ проверка фактического поведения сигнала

ЛИМС / ПАК
→ проверка тегов качества
```

Если источники противоречат друг другу, тег нужно помечать как:

```text
needs_validation
```

а не автоматически считать подтверждённым.
