## 🖼️ Как сделать скриншоты для README

### Запустите систему:
```bash
cd /Users/falexsun/code/Нефтекод/project
./scripts/start_demo.sh

# Подождите 30 секунд
```

### Откройте интерфейсы и сделайте скриншоты:

1. **Operator Console**
   ```bash
   open http://localhost:8000
   # Сделайте скриншот → docs/screenshots/operator-console.png
   ```

2. **Grafana Dashboard**
   ```bash
   open http://localhost:3000
   # Логин: admin, Пароль: neftekod-local
   # Dashboards → Q21 Shadow Pipeline
   # Скриншот → docs/screenshots/grafana-dashboard.png
   ```

3. **Запустите demo и скриншот Timeline**
   ```bash
   uv run python scripts/demo_replay.py --scenario exceedance --speed 100
   # В http://localhost:8000 появятся события
   # Скриншот → docs/screenshots/timeline-events.png
   ```

4. **Процесс replay**
   ```bash
   # Во время выполнения demo_replay.py
   # Скриншот терминала → docs/screenshots/demo-replay.png
   ```

5. **Prometheus**
   ```bash
   open http://localhost:9090
   # В поле ввести: neftekod_q21_current_ppm
   # Скриншот → docs/screenshots/prometheus-metrics.png
   ```

6. **API Docs**
   ```bash
   open http://localhost:8000/docs
   # Скриншот → docs/screenshots/api-docs.png
   ```
