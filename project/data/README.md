# Данные установки

Реальные технологические выгрузки и локальная БД не входят в Git-репозиторий.
Это сохраняет их вне общедоступного дерева исходного кода и не привязывает
клонированную копию к абсолютным путям на компьютере разработчика.

Для replay/обучения положите согласованные с владельцем данных файлы в этот
каталог или настройте источники данных согласно `configs/` и `scripts/`.
Исходный код, конфигурации, тесты и модели для Q21 находятся в `project/`.
