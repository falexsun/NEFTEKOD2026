# Нефтекод: Описания тегов АВТ 242000

## Введение

Данный документ содержит полное техническое описание всех тегов системы автоматизированного управления установкой атмосферно-вакуумной перегонки нефти (АВТ 242000). Описания включают назначение, тип сигнала, единицы измерения и эксплуатационный контекст каждого тега.

---

## 1. Атмосферная колонна (К-1)

### 1.1 Основные параметры колонны

#### AIT_242101
- **Описание**: Анализатор состава верхнего продукта атмосферной колонны
- **Тип сигнала**: Аналоговый вход (AI)
- **Единицы измерения**: % мольной доли
- **Назначение**: Непрерывный контроль качественного состава верхнего погона (газов и легких фракций). Используется для оптимизации режима ректификации и предотвращения уноса ценных компонентов.

#### FIC_242102
- **Описание**: Регулятор расхода питания атмосферной колонны
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: м³/ч
- **Назначение**: Поддержание заданного расхода сырой нефти, поступающей на разделение. Критический параметр для стабильности процесса и качества продуктов.

#### LIC_242103
- **Описание**: Регулятор уровня в кубе атмосферной колонны
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: %
- **Назначение**: Поддержание оптимального уровня мазута в нижней части колонны. Предотвращает перелив и обеспечивает стабильную работу насосов откачки.

#### PIC_242104
- **Описание**: Регулятор давления в атмосферной колонне
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: кПа
- **Назначение**: Поддержание оптимального давления в колонне для обеспечения эффективного разделения фракций. Предотвращает аварийные ситуации при превышении давления.

#### TIC_242105
- **Описание**: Регулятор температуры верха атмосферной колонны
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Контроль температуры верхнего продукта для обеспечения требуемого фракционного состава. Влияет на качество бензиновой фракции.

### 1.2 Боковые погоны

#### FIC_242106

- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: м³/ч
- **Назначение**: Контроль отбора легкого газойля с верхней тарелки бокового отбора. Оптимизирует выход целевых фракций.

#### TIC_242107

- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Поддержание температуры легкого газойля в заданном диапазоне для обеспечения требуемых физико-химических свойств продукта.

#### FIC_242108
- **Описание**: Регулятор расхода бокового погона 2 (тяжелый газойль)
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: м³/ч
- **Назначение**: Контроль отбора тяжелого газойля с нижней тарелки бокового отбора. Балансирует выход дизельных фракций.

#### TIC_242109
- **Описание**: Регулятор температуры бокового погона 2
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Обеспечение термического режима тяжелого газойля для соответствия спецификациям дизельного топлива.

### 1.3 Система орошения

#### FIC_242110
- **Описание**: Регулятор расхода верхнего орошения колонны К-1

- **Назначение**: Подача охлажденного конденсата на верх колонны для обеспечения эффективной ректификации и предотвращения уноса тяжелых фракций.

#### TIC_242111

- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Контроль температуры орошения для оптимизации теплового баланса колонны и четкости разделения фракций.

## 2. Вакуумная колонна (К-2)

### 2.1 Основные параметры

#### PIC_242201
- **Описание**: Регулятор вакуума в вакуумной колонне
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: кПа (абс.)
- **Назначение**: Поддержание глубокого вакуума (5-8 кПа) для перегонки мазута при пониженных температурах, предотвращая термический крекинг.

#### TIC_242202
- **Описание**: Регулятор температуры питания вакуумной колонны
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Контроль температуры мазута перед вводом в вакуумную колонну (обычно 380-400°C). Критичен для предотвращения коксообразования.

#### LIC_242203
- **Описание**: Регулятор уровня в кубе вакуумной колонны
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: %
- **Назначение**: Поддержание уровня гудрона в нижней части колонны для стабильной работы системы вакуумирования и откачки продукта.

#### FIC_242204
- **Описание**: Регулятор расхода вакуумного газойля
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: м³/ч
- **Назначение**: Контроль отбора вакуумного газойля – ценного сырья для каталитического крекинга и производства масел.

#### TIC_242205
- **Описание**: Регулятор температуры вакуумного газойля
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Обеспечение требуемого температурного режима вакуумного газойля для соответствия технологическим требованиям.

### 2.2 Система циркуляционного орошения

#### FIC_242206

- **Назначение**: Подача охлажденного продукта обратно в колонну для улучшения разделения и предотвращения перегрева.

#### TIC_242207
- **Описание**: Регулятор температуры циркуляционного орошения
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Контроль температуры циркулирующего потока для оптимизации теплового режима вакуумной колонны.

## 3. Печь подогрева (П-1)

### 3.1 Трубчатая печь

#### TIC_242301
- **Описание**: Регулятор температуры в радиантной секции печи
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Контроль температуры нагрева сырья в радиантных трубах (до 350-370°C). Предотвращает локальный перегрев и коксообразование.

#### FIC_242302
- **Описание**: Регулятор расхода топливного газа в печь
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: м³/ч (н.у.)
- **Назначение**: Управление подачей топлива для поддержания требуемой тепловой мощности печи с оптимальной энергоэффективностью.

#### PIC_242303
- **Описание**: Регулятор давления топливного газа
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: кПа
- **Назначение**: Стабилизация давления газа перед горелками для обеспечения равномерного горения и безопасности.

#### AIT_242304
- **Описание**: Анализатор кислорода в дымовых газах
- **Тип сигнала**: Аналоговый вход (AI)
- **Единицы измерения**: % об.
- **Назначение**: Контроль полноты сгорания топлива. Оптимальное содержание О₂ 2-3% обеспечивает максимальный КПД печи.

#### TIC_242305
- **Описание**: Регулятор температуры дымовых газов
- **Тип сигнала**: Аналоговый вход/выход (AI/AO)
- **Единицы измерения**: °C
- **Назначение**: Мониторинг температуры уходящих газов для оценки эффективности теплоотдачи и работы конвективной секции.

## 6. Система аварийной защиты и блокировок

### 6.1 Аварийные сигналы

#### PAH_242601
- **Описание**: Сигнализатор высокого давления в колонне К-1
- **Тип сигнала**: Дискретный выход (DO)
- **Единицы измерения**: Логический (Аварія/Норма)
- **Назначение**: Активация при превышении максимально допустимого давления. Инициирует процедуры аварийного сброса.

#### TAH_242602
- **Описание**: Сигнализатор высокой температуры в печи П-1
- **Тип сигнала**: Дискретный выход (DO)
- **Единицы измерения**: Логический (Аварія/Норма)
- **Назначение**: Предупреждение о перегреве труб печи. Предотвращает прогар и аварийные остановы.

#### LAL_242603
- **Описание**: Сигнализатор низкого уровня в кубе К-1
- **Тип сигнала**: Дискретный выход (DO)
- **Единицы измерения**: Логический (Аварія/Норма)
- **Назначение**: Защита насосов от сухого хода при критическом снижении уровня мазута.

#### FAL_242604
- **Описание**: Сигнализатор низкого расхода питания
- **Тип сигнала**: Дискретный выход (DO)
- **Единицы измерения**: Логический (Аварія/Норма)
- **Назначение**: Обнаружение остановки или критического снижения подачи сырья, требующего перехода на режим малой производительности.

### 6.2 Система блокировок (Interlock)

#### XSV_242605
- **Описание**: Запорный клапан аварийного сброса давления
- **Тип сигнала**: Дискретный выход (DO)
- **Единицы измерения**: Логический (Открыт/Закрыт)
- **Назначение**: Автоматическое открытие при аварийном росте давления для сброса паров в факельную систему.

#### XSV_242606
- **Описание**: Клапан отсечки топлива на печь П-1
- **Тип сигнала**: Дискретный выход (DO)
- **Единицы измерения**: Логический (Открыт/Закрыт)
- **Назначение**: Быстрое перекрытие подачи газа при аварийных ситуациях (потеря пламени, высокая температура, низкий расход сырья).

#### ESD_242607
- **Описание**: Кнопка аварийного останова установки (Emergency Shutdown)
- **Тип сигнала**: Дискретный вход (DI)
- **Единицы измерения**: Логический
- **Назначение**: Ручная инициация процедуры полного останова установки при критических ситуациях.

## Приложение А: Типы сигналов

| Обозначение | Тип | Описание |
|-------------|-----|----------|
| AI | Analog Input | Аналоговый входной сигнал (4-20 мА, 0-10 В) |
| AO | Analog Output | Аналоговый выходной сигнал (4-20 мА, 0-10 В) |
| DI | Digital Input | Дискретный входной сигнал (контакт, напряжение) |
| DO | Digital Output | Дискретный выходной сигнал (реле, транзистор) |

## Приложение Б: Префиксы функциональных обозначений

| Префикс | Параметр | Примеры |
|---------|----------|---------|
| A | Анализ (Analysis) | AIT - анализатор с индикацией и передачей |
| F | Расход (Flow) | FIC - регулятор расхода с индикацией |
| L | Уровень (Level) | LIC - регулятор уровня, LAL - сигнализатор низкого уровня |
| P | Давление (Pressure) | PIC - регулятор давления, PAH - сигнализатор высокого давления |
| T | Температура (Temperature) | TIC - регулятор температуры, TAH - сигнализатор высокой температуры |
| SS | Состояние (Status Switch) | SSI - индикатор состояния оборудования |
| XS | Положение (Position Switch) | XSV - запорный клапан с контролем положения |
| VSD | Variable Speed Drive | Частотно-регулируемый привод |
| ESD | Emergency Shutdown | Система аварийного останова |

## Приложение В: Нормальные рабочие диапазоны

### Атмосферная колонна К-1
- Давление верха: 120-150 кПа
- Температура верха: 140-160°C
- Температура низа: 340-360°C
- Уровень в кубе: 40-60%

### Вакуумная колонна К-2
- Вакуум: 5-8 кПа (абс.)
- Температура ввода сырья: 380-400°C
