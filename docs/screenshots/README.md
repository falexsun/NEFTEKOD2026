# Скриншоты

Добавьте сюда скриншоты работающей системы:

1. operator-console.png - главный интерфейс
2. grafana-dashboard.png - Grafana метрики
3. timeline-events.png - лента событий
4. demo-replay.png - процесс replay
5. prometheus-metrics.png - Prometheus
6. api-docs.png - Swagger UI

Для создания скриншотов:
1. Запустите систему: ./scripts/start_demo.sh
2. Откройте http://localhost:8000
3. Сделайте скриншоты (Cmd+Shift+4 на Mac)
4. Сохраните в эту папку
